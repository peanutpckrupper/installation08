## Installation 08 1.1

**New**
- Loading screens with a progress bar while a game, a mission or a restart loads, and while returning to the menu.
- PS5 package for prospero-win: copy it and your MCC files to the console over FTP, no PC tools needed. See `ps5/README-PS5.txt`.

**Fixes**
- Games now find their files when Installation 08 is started from outside the MCC folder (it switches to the MCC folder itself).
- Under Wine, MCC's own XAudio 2.9 is put in the prefix when it only has Wine's.

**Downloads**
- `Installation08-1.1.zip` — Windows PC.
- `Installation08-PS5.zip` — PS5 with prospero-win.

No game files are included; you need your own copy of Halo: The Master Chief Collection.
The PS5 package contains Wine and prospero-win files (LGPL 2.1+, source at github.com/mpereiraesaa/prospero-win) and DXVK 2.6.2 (zlib).
